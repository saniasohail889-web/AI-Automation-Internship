# Day 14 — Prompt Engineering

## Objective

The objective of Day 14 was to learn how to write specific, structured, and reliable prompts that can be used in automation workflows.

## Prompt Framework

The prompts were created using the following framework:

ROLE → CONTEXT → TASK → RULES → OUTPUT FORMAT → EXAMPLES

## Prompts Created

Five reusable prompts were created for:

1. Lead Qualification
2. Email Classification
3. CV Analysis
4. Complaint Classification
5. Support Reply Generation

## Testing

Each prompt was tested with 3 different sample inputs.

Total tests completed:

- 5 prompts
- 3 tests for each prompt
- 15 test cases in total

The outputs were recorded and included in the Prompt Library.

## Output Format

Each prompt was designed to return a strict JSON format so that the results can be easily used in automation workflows.

## Deliverable

The main deliverable for this task is:

`Prompt-Library.pdf`

It contains all 5 prompts and their test inputs and outputs.

## What I Learned

I learned how structured prompts can make AI responses more consistent and reliable. I also learned that specifying the role, task, rules, and output format is important when using AI in automation workflows.
